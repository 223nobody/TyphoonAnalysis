# 绪论图片 ChatGPT Image 提示词

## 说明

本文件根据以下两份材料整理：

- 参考样式：`基于会员制的大学生学习资源交流平台的设计与实现.docx` 中第 1 章“绪论”配图风格
- 内容依据：`论文-基于AI的台风数据分析与可视化平台设计与实现_完整版.md` 中“第 1 章 绪论”内容

目标不是生成艺术插画，而是生成**适合本科毕业论文绪论章节插入的学术型信息图**。参考样式的共同特征如下：

- 白色背景，整体简洁，适合 Word 排版
- 蓝色为主色，辅以浅蓝、灰蓝
- 横向构图，优先 4:3 或 16:9
- 扁平化矢量信息图风格，不要写实照片
- 标题位于顶部居中，图内文字为简体中文
- 结构图、框架图、趋势图、研究路径图为主
- 图标简洁，箭头清晰，模块边框规整，论文感强

- 如果你希望最大程度接近参考论文风格，优先生成“白底、蓝色主色、横向结构图、中文标题清晰”的版本。
